# Changelog

## Unreleased — safety and maintainability pass

- Reframed the project as an educational awareness checklist rather than a cardiac risk screening calculator.
- Removed “low risk” output and success styling that could provide false reassurance.
- Added optional systolic and diastolic inputs.
- Changed very high blood-pressure guidance to encourage prompt professional contact; the number alone is not labelled an emergency.
- Added multiple symptom prompts for potential emergency signs.
- Separated fistula/graft vibration prompts from catheter/dressing prompts.
- Added input validation and expanded automated tests.
- Renamed `main (1).py` to `main.py` to match documentation.
- Updated safety notice, references, setup instructions, `.gitignore`, and CI test workflow.
- Clinical review and validation remain outstanding; this project must not be used as a medical screening product.
